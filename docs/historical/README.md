# Historical Repository Records

This directory contains prior audit reports, phase checklists, implementation summaries, compatibility studies, and release records that were formerly stored at repository root.

The documents are preserved as historical evidence. Their claims are date- and commit-scoped and do not override the current state recorded in [`PROJECT_STATUS.md`](../../PROJECT_STATUS.md), [`ARCHITECTURE.md`](../../ARCHITECTURE.md), or the active evidence documents in [`docs/evidence/`](../evidence/).

The relocation is organizational only. Historical prose and conclusions were not silently rewritten. Some records refer to build outputs, reports, or paths that existed only during the original audit and are intentionally not recreated as active dependencies.
